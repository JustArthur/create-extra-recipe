## _Description_

A lightweight mod that expands crafting possibilities for **Vanilla Minecraft** and improves integration with the [Create](https://modrinth.com/mod/create) ecosystem.

This mod introduces **new crafting recipes, progression tweaks, and automation-friendly mechanics**, while staying faithful to the vanilla gameplay experience.

## _Compatibility_

This mod supports both **NeoForge** and **Fabric**.

**NeoForge**:
- [Vanilla Backport](https://modrinth.com/mod/vanillabackport) (Optional)
- [Create: Dragons Plus](https://modrinth.com/mod/create-dragons-plus) (Optional)
- [Create Mechanical Spawner](https://modrinth.com/mod/create-mechanical-spawner) (Optional)

**Fabric**: 
- Works standalone (no compatibility)
- **⚠️ The Fabric version is no longer updated ⚠️**
